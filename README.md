# Dia da Mulher — React + Tailwind

Versão modernizada de um projeto inicial (HTML) para uma SPA em React com Tailwind CSS.

## Requisitos
- Node.js 18+ (recomendado)

## Rodar localmente

```bash
npm install
npm run dev
```

Abra o endereço exibido no terminal.

## Build

```bash
npm run build
npm run preview
```
